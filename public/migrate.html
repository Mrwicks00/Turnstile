Migration assistant

The residual figure on the drain monitor isn't abstract — it's real testnet ZEC sitting in wallets that haven't moved it out of the sealed Orchard pool yet. This page runs an actual migration, end to end, using Zcash's own wallet software — so you can watch what closing that gap really looks like.

What this is, and isn't This is a real testnet transaction, run with a wallet we control, funded from a public faucet — not a tool that touches your funds or asks for your keys. A safe migration of your own ZEC has to happen in your own wallet, with your own keys, which this project will never request. What follows is a transparent demo of the exact steps that requires, run honestly in the open rather than described in the abstract.
How a migration actually works

  • Get a wallet that speaks the current spend rules

    zcashd's built-in wallet reached end-of-support in July 2026. The replacement is Zallet, Zcash's new standalone wallet — the one this demo uses, talking to our own synced zebrad node.

  • Check what's sitting in the pool

    The wallet reports its Orchard balance directly from the chain — no separate attestation step needed. If the balance is nonzero, it's movable.

  • Send it to a fresh address

    A normal shielded send — the same operation as spending — using z_sendmany. This is the whole "migration": there's no special instruction for it, because moving a note has always been the way out.

  • Confirm on chain

    Once mined, the transaction is visible like any other — and it should show up as a real balance change in this project's own independent indexer, the same one powering the drain monitor.

Try it yourself — a real testnet wallet, in this page
Testnet only. Client-side only. We never see this. Clicking below generates a real 24-word seed phrase and a real shielded wallet, entirely in your browser — nothing is ever sent to our server. Closing or refreshing this tab loses access to it; nothing is saved anywhere by us, so the only way back in is pasting your own saved seed phrase into "Import" below. This uses WebZjs, an unaudited, in-development library ("no reviews or audit, and come with no guarantees whatsoever," per its own docs) built on Zcash's official cryptography. Never paste in a real seed phrase, or one protecting real funds, on this or any page.

If your funds were received before this height, sync won't find them — when in doubt, use a lower number. Leaving this blank scans from a recent default, not from genesis.
